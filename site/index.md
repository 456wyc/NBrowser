<section class="block" id="features">
  <h2 class="sec-title">核心特性</h2>
  <p class="sec-sub">为投资流程而生的浏览器，而不是又一个带插件的浏览器</p>
  <div class="feat-grid">
    <div class="feat-card">
      <div class="feat-icon">📊</div>
      <div class="feat-title">按投资流程分空间</div>
      <div class="feat-desc">内置「盯盘 / 研究 / 复盘」三个空间，标签页与登录态彼此隔离；同一网站可在不同空间登录不同账号。</div>
    </div>
    <div class="feat-card">
      <div class="feat-icon">📈</div>
      <div class="feat-title">行情常驻</div>
      <div class="feat-desc">自选股行情在侧边栏常驻显示（涨红跌绿，A 股习惯），无需来回切页面看盘，支持自定义与智能分组。</div>
    </div>
    <div class="feat-card">
      <div class="feat-icon">🕒</div>
      <div class="feat-title">自动记录浏览轨迹</div>
      <div class="feat-desc">自动记录「我在哪只股票上花了多少时间」并聚合，解决复盘时「我那天到底看了啥」的问题。</div>
    </div>
    <div class="feat-card">
      <div class="feat-icon">🤖</div>
      <div class="feat-title">AI 只做信息整理</div>
      <div class="feat-desc">严禁预测价格与买卖建议，只输出事实摘要、利好 / 利空要点、关键数据、存疑点；社区内容标注「观点非事实」。</div>
    </div>
    <div class="feat-card">
      <div class="feat-icon">💬</div>
      <div class="feat-title">AI 助手 Copilot</div>
      <div class="feat-desc">Cmd / Ctrl + K 全局召唤，多轮会话持久化，内置自选 / 持仓 / 研究轨迹 / 笔记等只读数据工具与联网检索。</div>
    </div>
    <div class="feat-card">
      <div class="feat-icon">📝</div>
      <div class="feat-title">交易与复盘闭环</div>
      <div class="feat-desc">支持交割单导入与自然语言录入，自动计算盈亏、胜率，逐笔绑定复盘笔记，串联「交易 ↔ 决策依据」。</div>
    </div>

<section class="block" id="quick">
  <h2 class="sec-title">快速开始</h2>
  <p class="sec-sub">要求 Node 22+ 与 <a href="https://pnpm.io/" target="_blank" rel="noopener">pnpm</a></p>

```bash
# 安装依赖
pnpm install

# 启动开发模式（热重载）
pnpm dev

# 运行单元测试
pnpm test

# 打包（Windows NSIS 安装包）
pnpm dist
```

> 行情功能使用公开免费接口，无需任何 Key 即可使用。AI / Copilot / 策略等能力需要在「设置 → LLM」中填写可用的 OpenAI 兼容接口地址与 Key 后启用。

<section class="block" id="tech">
  <h2 class="sec-title">技术栈</h2>
  <p class="sec-sub">现代 Electron 桌面应用的务实选型</p>

| 维度 | 选型 |
| --- | --- |
| 运行时 | Electron 32 + Node 22 |
| UI | React 18 + TypeScript 5.7 |
| 构建 | electron-vite 5 + Vite 6 |
| 存储 | sql.js（SQLite WASM，纯内存 + 手动落盘） |
| 行情 | 东方财富 / 腾讯财经公开接口，Provider 可插拔 |
| LLM | OpenAI 兼容 `/chat/completions`，用户自填配置 |

</section>
