## 1. 产品概述

### 1.1 定位

一款面向个人投资者的**桌面端专用浏览器**。它不是通用浏览器的竞品，而是把「看盘 → 研究 → 复盘」这条投资主链路固化为产品结构：用浏览器承载用户本来就每天要打开的东方财富、同花顺、雪球、巨潮资讯等站点，并在浏览器外壳上叠加**自选股行情、浏览轨迹记录、股票识别、AI 信息整理**四层能力。

### 1.2 核心价值主张

1. **按投资流程分空间**：盯盘 / 研究 / 复盘三个空间彼此隔离，标签页与登录态互不串扰。
2. **行情常驻**：自选股行情在侧边栏常驻显示，无需来回切页面看盘。
3. **自动记录浏览轨迹**：自动把「我在哪只股票上花了多少时间」记录下来，解决复盘时"我那天到底看了啥"的问题。
4. **AI 只做信息整理，不做投资建议**：严格禁止预测价格与给出买卖建议，只输出事实摘要、利好/利空要点、关键数据、存疑点。

### 1.3 明确不做的事（Non-Goals）

- 不做行情交易下单（不对接券商交易接口）
- 不做行情图表、技术指标、K 线绘制
- 不做投资建议、目标价预测、买卖点提示
- 不做多端同步 / 云存储（纯本地单机）
- 不做通用浏览器的扩展生态、下载管理器、密码管理器

## 2. 术语表

| 术语 | 含义 |
| --- | --- |
| 空间（Space） | 工作区（内置 `watch` 盯盘、`research` 研究、`review` 复盘，可自定义增/删/改名），标签页与登录态彼此隔离 |
| 分区（Partition） | Electron session 分区，每个空间独立 `persist:space-<id>`，实现登录态隔离 |
| 标签（Tab） | 基于 `WebContentsView` 的网页视图，从属于某个空间 |
| 网页区域（Web Area） | 主窗口中除去侧边栏、标签栏、地址栏后留给网页内容的矩形区域 |
| 自选股（Watchlist） | 用户关注的股票列表，行情轮询的数据来源 |
| 行情（Quote） | 单只股票的实时快照：现价、涨跌幅、涨跌额、开/高/低/昨收、成交量、成交额 |
| 浏览轨迹（PageVisit） | 一次页面停留记录：URL、标题、关联股票、所属空间、开始时间、停留时长 |
| 标准股票代码 | 内部统一格式 `600519.SH` / `000001.SZ` / `430047.BJ` |
| 页面类型（PageType） | `announcement` 公告 / `news` 新闻 / `financial_report` 财报 / `community` 社区 / `general` 通用 |

## 3. 技术架构与约束

| 维度 | 选型 / 约束 | 来源 |
| --- | --- | --- |
| 运行时 | Electron 32 + Node 22 | `package.json` |
| UI 框架 | React 18 + TypeScript 5.7 | `package.json` |
| 构建 | electron-vite 5 + Vite 6（main / preload / renderer 三段式） | `electron.vite.config.ts` |
| 存储 | sql.js（SQLite WASM，纯内存 + 手动落盘），**不使用原生模块** | `src/main/db/index.ts` |
| 测试 | Vitest 2（仅覆盖纯函数） | `vitest.config.ts` |
| 进程通信 | `contextBridge` + 类型化 IPC（`src/shared/ipc.ts` 单一契约源） | `src/preload/index.ts` |
| 数据来源 | 东方财富公开行情/搜索接口（免费、无需 Key） | `src/main/quote/eastmoney-provider.ts` |
| LLM | OpenAI 兼容 `/chat/completions` 协议，用户自填 baseUrl / apiKey / model | `src/main/ai/llm-client.ts` |

**关键架构约束（必须遵守）**

- **A1** 主进程与渲染进程的所有通信必须走 `src/shared/ipc.ts` 定义的通道与类型，禁止新增裸字符串通道。
- **A2** 渲染进程无 Node 权限：`contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`；preload 只暴露 `invoke` / `onQuotesUpdated`，且 `invoke` 校验通道白名单。
- **A3** 主进程 IPC handler **不信任渲染进程入参**，每个 handler 均做类型与必填校验。
- **A4** 存储层用 sql.js 内存库，**必须手动持久化**（当前策略：5 秒定时 + `before-quit` 落盘）。
- **A5** 敏感信息（LLM API Key）存 `userData/config.json`，**不入库、不提交 git**；业务数据存 `userData/stock-browser.db`。
- **A6** 行情/股票识别/AI 等外部依赖必须抽象为 Provider / 纯函数，便于新增数据源与单测。

## 5. 数据模型

数据库：`userData/stock-browser.db`（sql.js，迁移版本号记录在 `PRAGMA user_version`，当前 `001_init`）。
时间统一为 **UTC 毫秒时间戳（integer）**。

| 表 | 用途 | 关键字段 | 状态 |
| --- | --- | --- | --- |
| `watchlist` | 自选股 | `symbol`(UNIQUE)、`name`、`sort_order`、`created_at` | ✅ |
| `bookmarks` | 书签 | `title`、`url`、`sort_order`、`created_at` | ✅ |
| `page_visits` | 浏览轨迹 | `url`、`title`、`symbol`、`space`、`started_at`、`duration_ms`（索引：space/symbol/started_at） | ✅ |

| `trades` | 交易记录 | `symbol`、`side`(buy/sell)、`price`、`quantity`、`traded_at`、`fee`、`source`、`confirmed`、`buy_reason`、`sell_reason`（唯一索引防重） | ✅（含自然语言录入、交割单导入、就地编辑、筛选、盈亏汇总） |
